## About

This is the public distribution hub for my software. It brings installers, portable applications, plugins, and other packaged solutions together in one place.

Downloads are published through **GitHub Releases**. This repository contains the hub's documentation and distribution terms. The source code for my products is not published here.

**A public download does not make a product open source.** The software remains proprietary and is provided under the [FrostLagoa Public Release License](LICENSE), unless a release explicitly identifies different terms for a particular product or component.

## Download a tool

1. Open [Releases](https://github.com/FrostLagoa/kallidos_hub/releases).
2. Choose the product and version you want. Each release title identifies its product; check its supported operating systems and requirements.
3. Expand **Assets** and download the installer, portable archive, or plugin package for your platform.
4. Follow the installation instructions in that release's notes or included documentation.

GitHub's automatically generated **Source code (zip)** and **Source code (tar.gz)** archives contain this repository's documentation, not the products' source code or installers.

**No software releases have been published yet.** Available products will be listed here as their first public releases become available.

## Versions and updates

Each product has its own release history. Releases use product-specific tags such as `product-name/v1.0.0` so multiple tools can share this hub.

Read the relevant release notes for changes, compatibility requirements, installation steps, and known limitations. Releases marked **Pre-release** are previews for evaluation and may be less stable. Use the full Releases list to find your product; the repository-wide “Latest” label may belong to a different tool.
